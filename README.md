# Wedding Invitation

A responsive, single-page wedding invitation inspired by the supplied reference.

## Open

Open `index.html` in a browser. No build step or dependencies are required.

## Customize

Edit the couple names, family details, schedule, and venue addresses in `index.html`. Change the wedding timestamp in `script.js` to update the countdown. Colors, typography, and layout are in `styles.css`.

The invitation artwork is stored in `images/cover.png` and `images/invitation-details.png`. Replace those files to update the posters. Fonts load from Google Fonts.

Background music is bundled at `audio/wedding-music.mp3`. It begins after the visitor opens the invitation and can be paused or resumed from the header. The track is “Meditation Impromptu 01” by Kevin MacLeod, licensed under CC BY 4.0; attribution and license links are included in the page footer.
